# Sistema de Gestão SLFood (Sabor Local)
Aplicativo de delivery independente e sistema de gestão completo desenvolvido para o restaurante Sabor Local. 

## Sobre o Projeto
O ecossistema do projeto é dividido em três frentes principais:
1. **App Cliente:** Focado na melhor experiência de pedido para o consumidor final.
2. **App Entregas:** Focado na logística e roteamento dos motoboys.
3. **Sistema de Gestão:** Painel administrativo para controle total do fluxo da loja.

## Funcionalidades Principais do Sistema de Gestão

* Dashboard para gerenciamento de pedidos em tempo real (Kanban de status).
* Controle de estoque e gerenciamento dinâmico do cardápio.
* Relatórios detalhados de vendas e atribuição manual ou automática de entregadores.

## Tecnologias Utilizadas
* **[FlutterFlow](https://flutterflow.io/):** Construção da interface (Frontend) e compilação dos aplicativos móveis e web.
* **[Xano](https://xano.com/):** Desenvolvimento do Backend e Banco de Dados relacional, responsável por toda a lógica de negócio, autenticação e integrações.
* **[n8n](https://n8n.io/) & Telegram API:** Orquestração do Agente de Inteligência Artificial para o atendimento ao cliente.
* **Gateways de Pagamento:** Processamento seguro via tokenização e padrão PCI DSS.
